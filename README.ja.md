# Spacekeeper

**[한국어](README.ko.md) · 日本語 · [English](README.md)**

macOS用のネイティブ整理アプリです。古いキャッシュ、完全に同じ内容の重複ファイル、大容量ファイルを確認して整理できます。SwiftUI・Foundation・CryptoKitを使用し、アカウント、サーバー、解析SDKは不要です。

## ビルドと起動

macOS 13以降、Swift 5.9以降のXcode Command Line Toolsが必要です。

```sh
git clone https://github.com/ddossss/spacekeeper.git
cd spacekeeper
zsh scripts/build-app.sh
open codex-work/dist/Spacekeeper.app
```

現在のMacのアーキテクチャ向けにビルドし、ローカルのアドホック署名を適用します。Developer ID署名・公証は含まれません。

## 言語の選択

サイドバー下部の**言語**から、**한국어・日本語・English**を選択できます。すぐに反映され、次回起動後も保持されます。スキャン結果と選択したファイルは維持されます。初回は対応するシステム言語を使用し、該当しない場合は英語になります。

メニュー、結果、確認画面、アプリのエラー、整理履歴、日時・容量表示が切り替わります。macOSのファイル選択画面、権限確認、OS由来のエラーはシステム言語に従います。新しい履歴は後から別の言語でも表示できます。旧版の自由形式のエラー詳細は元の言語で残ります。

## 主な機能

- **概要：** 実際のストレージ容量、使用量、空き容量を表示。
- **キャッシュ整理：** Chrome、Edge、Firefox、Brave、Spotify、VS Codeの既知のキャッシュが対象。実行中のアプリや最近使用・変更したファイルを除外。
- **重複ファイル：** サイズで候補を絞り、SHA-256で全内容を比較。少なくとも1個のコピーを保持。
- **大容量ファイル：** 選択したフォルダから10 MB・100 MB・500 MB・1 GB以上のファイルを検索。
- **インストール済みアプリ：** 名前、バージョン、場所を確認。FinderとmacOSのログイン項目へ移動。
- **定期整理：** 毎日・毎週の実行時刻、保持期間、対象アプリ、1回の容量上限を設定。
- **除外フォルダ：** スキャンと整理の両方で適用。
- **整理履歴・復元：** 移動したファイルを確認し、既存ファイルを上書きせずに復元。

定期整理は初期状態ではオフです。**定期整理**で有効にして設定を保存すると、ログイン中はアプリを終了しても実行されます。スリープ中に逃した実行は復帰後に行われることがあります。個人の書類や重複ファイルは自動で整理しません。

## 整理と復元

1. キャッシュをスキャンするか、重複・大容量ファイル画面で対象フォルダを選びます。
2. 不要なファイルを選択し、**選択項目を確認**でフルパスを確認します。
3. **ゴミ箱へ移動**を実行します。
4. **整理履歴**で結果を確認し、必要なら元の場所に復元します。

ゴミ箱へ移動しただけでは空き容量は増えません。内容を確認してからFinderでゴミ箱を空にしてください。空にしたファイルは復元できません。APFSのクローン、スナップショット、圧縮により実際の空き容量は表示サイズと異なる場合があります。

システム領域、ユーザーLibrary、アプリ・書類パッケージ、隠しファイル、開発用依存フォルダ、シンボリックリンク、ハードリンク、iCloud項目は個人ファイルのスキャンから除外します。他のクラウド同期フォルダに完全ダウンロードされたファイルは通常ファイルとして扱われる場合があるため、必要に応じて除外してください。

移動直前に状態を再確認し、重複ファイルは残すコピーも再度ハッシュ検証します。他のプロセスによる同時変更を完全に禁止する仕組みではないため、対象ファイルを編集するアプリは終了して使用してください。

キャッシュは最低7日、初期設定では14日間保持します。スキャンは20万ディレクトリ項目までです。ゴミ箱の自動消去、管理者権限の要求、パスワード・Cookie・閲覧履歴の削除、自動アンインストールは行いません。

## 保存場所とテスト

アプリは`codex-work/dist/Spacekeeper.app`、言語・整理設定・履歴は`codex-work/state/`に保存され、Gitの対象外です。定期整理を有効にした場合のみ`~/Library/LaunchAgents/local.spacekeeper.cache-cleanup.plist`が作成されます。アプリ移動後は設定を保存し直し、プロジェクト移動後は再ビルドしてください。アプリを削除する前に定期整理をオフにして保存してください。

```sh
python3 scripts/check-localization.py
zsh scripts/test.sh
zsh scripts/build-app.sh
zsh scripts/ui-smoke.sh
```

テストはプロジェクト内で生成したファイルを使用します。ネイティブのゴミ箱テストでも生成したファイルだけを移動して復元します。実際の個人書類やキャッシュは整理しません。

詳細な安全上の範囲、復元条件、開発手順は[英語の説明](README.md)を参照してください。CCleanerとは提携していない独立したプロジェクトです。
